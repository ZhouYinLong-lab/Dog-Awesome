## 📝 收录标准

- 项目必须**开源**，有明确的开源协议
- 有一定的社区活跃度（Stars、最近更新等）
- 对开发者或创作者有实际价值
- 文档清晰，上手友好

## 🤝 贡献方式

欢迎通过 Issue 或 PR 推荐你觉得值得收录的开源项目！
